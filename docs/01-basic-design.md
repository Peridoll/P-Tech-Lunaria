# Lunaria 基本設計（初期プロトタイプ）

## 目的
FiveM内で進行できる人狼ゲームの基盤を、既存フレームワークに依存せず実装する。

## 責務
- `ptech_lunaria_game`: ロビー、役職、昼夜進行、投票、夜行動、勝敗判定
- 将来的なUI、役職追加、ログ、演出などは独立した追加モジュールとして検討

## MVPルール（暫定）
- 参加者4人以上。4〜6人：人狼1人、7人以上：人狼2人。それ以外は占い師1人と村人
- 初日は夜から開始。進行役が手動で昼・夜を切り替える
- 夜の人狼襲撃は人狼全員の最多票、同数なら襲撃なし
- 占い師は一夜につき1度だけ、生存者1名を占える
- 昼の処刑は生存者の最多票、同数なら処刑なし
- 生存人狼0で村人勝利、生存人狼数が他陣営以上で人狼勝利
- 脱落者の役職は公開。役職配布・占い結果は本人だけに通知
- 時計、マップ移動、ボイスミュート、複雑な役職は未実装

## セキュリティ
- 進行の確定処理は全てサーバーで実行
- 管理コマンドはサーバーコンソールまたはACE `lunaria.admin` 保有者だけ
- コマンドの入力値はサーバーで検証
- ゲーム途中の切断は脱落として処理、再参加は次ゲームから
- 暫定チャット通知は `chat` リソースのイベントに依存。未導入環境は通知用アダプターが必要

## 今後確認する仕様
- 開催場所の隔離方法、インスタンス（routing bucket）
- 複数ルーム同時開催、見学者・GM権限
- ボイス制御と死亡者チャット
- 制限時間と自動進行
- UI/NUI、効果音、役職拡張、永続ログ
